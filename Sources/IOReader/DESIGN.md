# IOReader

## 意図の整理

### stdin系

cinの模倣動作。トークン単位動作をする。

文字列の単語扱いは、単数に限定する。
単語の配列や単語の二次配列は、特殊なのでstdin系統から除外していく。

以下の二つは特例でそのままで残す。

- 文字列 = 文字列.stdin(columns:)
- 文字列配列 = 文字列配列.stdin(rows:columns:)

stdin系の文字列と二次元配列の組み合わせは文字列配列に限定する。
（文字列の単語単位入力は鉄則本では欲しいが、AtCoderの普段の問題では必要ないため）
単語の二次元配列は削除。

- 文字列.stdin(rows:)
- 文字列配列.stdin(rows:)
